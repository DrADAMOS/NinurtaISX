# تحديث مركز أدوات نينورتا

## ما الذي تغير؟
- إضافة صفحة مستقلة باسم **مركز أدوات نينورتا**، وهي الصفحة الافتراضية عند فتح التطبيق.
- تجميع 11 مدخلاً وظيفياً في أربع مجموعات: الذكاء والتحليل، إدارة الاستثمار، السوق والبيانات، الحاسبات والتعلم.
- إضافة بحث فوري داخل المركز.
- كل بطاقة تنقل إلى شاشة التطبيق الموجودة فعلياً؛ لم تتم إعادة كتابة وظائف المحافظ أو كشف الحساب أو الحاسبات.
- تقليص شريط التنقل إلى زر مركز الأدوات وزر سريع لإشارات السوق، مع بقاء زر حاسبة العمولة الموجود في الرأس.
- إضافة شاشة حاسبات سهمي إلى مسار التطبيق وربطها بمدخل مستقل.

## الأدوات المربوطة
1. ذكاء المستثمر
2. ذكاء السوق
3. تحليل المصارف
4. محفظة المستثمر
5. كشف الحساب
6. إشارات حركة السوق
7. نبض السوق والحركة
8. دليل الأسهم
9. حاسبة العمولة ISXC
10. حاسبات سهمي (11 حاسبة داخل الشاشة)
11. نصائح وأدوات المستثمر

## تطبيق الحزمة الكاملة
1. أوقف خادم Vite.
2. خذ نسخة احتياطية من مجلد المشروع الحالي كاملاً.
3. فك `Ninurta-Current-Tools-Center.zip` إلى مجلد جديد، أو استخرج محتوياته فوق نسخة المشروع بعد أخذ النسخة الاحتياطية.
4. شغّل:
   ```powershell
   npm ci
   npm run lint
   npm run build
   npm test
   npm run dev
   ```

## تطبيق التصحيح فقط
التصحيح مخصص للنسخة التي سبق أن طُبّق عليها استرجاع ذكاء المستثمر وذكاء السوق. شغّل `Apply-Tools-Center.ps1` من PowerShell داخل جذر المشروع.

## حدود التحقق
تم فحص صياغة ملفات TSX المعدلة بمترجم TypeScript عبر transpileModule، والتحقق من وجود المكونات ومسارات الاستيراد الأساسية. لم يكتمل `npm ci` في بيئة إعداد الحزمة بسبب انتهاء مهلة تنزيل الاعتماديات؛ لذلك لم يتم تأكيد `tsc` أو Vite production build أو الاختبارات. يجب تنفيذ أوامر التحقق أعلاه على جهاز التطوير قبل اعتماد النسخة.
