# Phase 17 — بوابة المراجعة: فصل جودة البيانات عن التوصية، وأسباب محددة بدل «قيد المراجعة»

## ما سبب العلق (من بياناتك الفعلية)
- `assessStockDataQuality` كان يُرجع حالة واحدة، والتوصية تُفتح فقط عند `verified`. لكن `technicalLevelsAsOf` غير موجود في أي سهم من 105، فكان الخطأ `TECHNICAL_LEVELS_NOT_VERIFIED_FOR_CURRENT_SESSION` يظهر دائماً ولا يمكن أن يصير أي سهم `verified`.
- كل سهم له دفتر أوامر كان يأخذ `ORDER_BOOK_SOURCE_TIMESTAMP_NOT_VERIFIED` تلقائياً.
- العلامة `DIRECTORY_RECONCILIATION_REVIEW_REQUIRED` (27 سهماً) تُضاف عند مزامنة الدليل ولا يوجد أي مسار لإزالتها.
- التنبيهات السعرية كانت تتطلب `verified` أيضاً، فلا تُفعَّل أبداً.

## ما الذي تغيّر
1. `src/utils/reviewGate.ts` (جديد):
   - **جودة البيانات** = اكتمال المصدر 40% + حداثة الجلسة 30% + اتساق السعر 30% (درجة 0–100، مع أسباب).
   - **التوصية** لا تُفتح إلا عند: جودة غير مانعة، سهم متداول، مطابقة الدليل مؤكدة، سجل رسمي ≥ 20 جلسة، وآخر شمعة موثقة بفارق ≤ 3 جلسات تداول عن سعر الجلسة. المؤشرات (RSI14، MA20، MA50، دعم/مقاومة) تُحسب من الشموع الموثقة نفسها.
   - كل حالة مانعة تُرجع: رمز + عنوان + تفصيل بالأرقام + الإجراء المطلوب.
2. `stocksData.ts` و`stock.ts`: حقلان جديدان `dataQuality` و`recommendationGate`. الحقلان القديمان `dataQualityStatus/Issues` لم يتغيّرا (اختباراتك القديمة سليمة).
3. الواجهات: تفاصيل السهم، التوصيات، دليل السوق تعرض السبب المحدد. التنبيهات السعرية تعمل عندما لا تكون جودة السعر «غير كافية».
4. `scripts/confirm-directory-match.py`: يعرض الرموز الـ27 مع الاسم القديم والحالي، ويؤكد **فقط** الرموز التي تسمّيها.

## التشغيل
```
powershell -NoProfile -ExecutionPolicy Bypass -File ".\phase17patch\Apply-Phase17-Review-Gate.ps1"
```
السكربت يتحقق من بصمة الملفات (حتى لا يمحو تعديلات بعد Phase 16)، ينسخ احتياطاً إلى `backups\phase17-review-gate-*`، ثم يشغّل اختبارات البوابة + `npm run lint` + `npm run build`، ويتراجع تلقائياً عند أي فشل.

## لفتح التوصية فعلياً
1. `Fetch-Official-History.bat` ثم `npm run data:import-official` (يعالج `INDICATORS_STALE`).
2. `python scripts/confirm-directory-match.py` راجع القائمة، ثم `--confirm رمز1 رمز2 ...` للمتطابق فعلاً.

## ثوابت قابلة للتعديل (أعلى `reviewGate.ts`)
`MAX_INDICATOR_LAG_TRADING_DAYS = 3` · `MIN_HISTORY_ROWS = 20` · `MAX_STALE_TRADING_DAYS = 3`
جلسات التداول = الأحد–الخميس، والعطل الرسمية غير مضمّنة.

## ملاحظات
- المؤشر MACD لم يعد يُعرض من حقل بلا مصدر (يظهر «غير محسوب»).
- نص التوصية نفسه (`signal`) ما زال من المحرك الحالي، والبوابة تحكم متى يظهر فقط.
- الاختبار `historical return uses first available candle` في `tests/marketAnalytics.test.ts` يفشل في النسخة الأصلية أيضاً (19.999999999999996 ≠ 20)، لذلك لا يشغّل السكربت `npm test` كاملاً.

## تحقق إضافي قبل التسليم
- جرى اختبار `confirm-directory-match.py` على مشروع مؤقت ببيانات تجريبية منفصلة عن بياناتك.
- عرض السكربت الرمزين المعلّمين مع الاسمين القديم والحالي ونسبة التشابه.
- عند تأكيد `BNAI` وحده، أضاف `directoryMatchConfirmed` إلى `BNAI` فقط، وترك `TZNI` دون تغيير، وأنشأ نسخة احتياطية من `stocks.json`.
- هذا الاختبار يتحقق من سلوك السكربت والنسخ الاحتياطي فقط؛ لا يعني أن أي مطابقة حقيقية قد تم تأكيدها.
- لم يتم تشغيل `Apply-Phase17-Review-Gate.ps1` على مشروعك الأصلي، ولم يتم ادعاء نجاح `lint` أو `build` في بيئة الفحص هذه.
